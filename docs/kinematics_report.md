## How to Solve Forward Kinematics (Step-by-Step)

**Given:** Joint angles q1, q2, q3, q4, q5, q6 in degrees.

**Steps:**

1. Convert to radians: q_i_rad = q_i_deg * pi / 180

2. Active DH angle for revolute joints: theta_i = theta_offset_i + q_i_rad (all offsets = 0 for PUMA 560)

3. Compute each A_i matrix using Standard DH:

$$A_i = \begin{bmatrix} c\theta_i & -s\theta_i c\alpha_i & s\theta_i s\alpha_i & a_i c\theta_i \\ s\theta_i & c\theta_i c\alpha_i & -c\theta_i s\alpha_i & a_i s\theta_i \\ 0 & s\alpha_i & c\alpha_i & d_i \\ 0 & 0 & 0 & 1 \end{bmatrix}$$

4. Chain multiply: T06 = A1 * A2 * A3 * A4 * A5 * A6

5. Extract end-effector from T06:
   - Position p = column 4 (rows 1-3): [T[0,3], T[1,3], T[2,3]]
   - Rotation R = top-left 3x3 block
   - Roll = atan2(R[2,1], R[2,2]) | Pitch = atan2(-R[2,0], sqrt(R[0,0]^2+R[1,0]^2)) | Yaw = atan2(R[1,0], R[0,0])

---

## How to Solve Inverse Kinematics (Step-by-Step)

**Given:** Target pose (px, py, pz, roll, pitch, yaw)

**Method: Damped Least Squares (Levenberg-Marquardt)**

**Step 1:** Build 4x4 target matrix T_target from position + rotation matrix R_target.

**Step 2:** Initialize seed q(0) (use current joints, zero, or perturbed guesses).

**Step 3:** Iterate for k = 0, 1, 2, ..., max_iter:

  a. Compute Tc = FK(q_k). Extract p_c, R_c.

  b. Compute 6x1 error vector:
     - Position error:   dp = p_target - p_c   (3x1)
     - Rotation error:   dr = (1/2) * [ (Rc^T Rt)[2,1]-(Rc^T Rt)[1,2], (Rc^T Rt)[0,2]-(Rc^T Rt)[2,0], (Rc^T Rt)[1,0]-(Rc^T Rt)[0,1] ]  (3x1)
     - Full error:       e = [dp; dr]   (6x1)

  c. Build numerical 6x6 Jacobian J (delta = 1e-6 rad per joint).

  d. DLS update with damping lambda = 1e-3:

$$\Delta q = (J^T J + \lambda I)^{-1} J^T \varepsilon$$

  e. Clamp step: if max|dq| > 0.4 then dq = dq * 0.4 / max|dq|

  f. Update: q_{k+1} = q_k + dq

**Step 4:** FK-validate the result:
  - Position error ||p_FK - p_target|| < 1e-4 m (0.1 mm) = PASS
  - Rotation error ||dr|| < 1e-3 rad (0.057 deg) = PASS
