## How to Solve Forward Kinematics (Step-by-Step)

**Given:** Joint angles $q_1, q_2, q_3, q_4, q_5, q_6$ (in degrees, convert to radians)

**Steps:**

1. Convert each joint angle to radians: $q_i^{rad} = q_i^{\circ} \times \pi / 180$

2. Substitute into the active DH angle:
   - For revolute joints: $\theta_i = \theta_{i,offset} + q_i = 0 + q_i$ (all offsets are zero for PUMA 560)

3. Compute each $A_i$ matrix using Standard DH formula above

4. Multiply in sequence: $T_0^6 = A_1 A_2 A_3 A_4 A_5 A_6$

5. Extract end-effector:
   - **Position:** $p = T_0^6[0:3, 3]$ — top-right 3×1 column
   - **Rotation:** $R = T_0^6[0:3, 0:3]$ — top-left 3×3 sub-matrix
   - **Euler angles (XYZ roll-pitch-yaw from ZYX):**
     $$roll = \text{atan2}(R_{32}, R_{33}), \quad pitch = \text{atan2}(-R_{31}, \sqrt{R_{11}^2+R_{21}^2}), \quad yaw = \text{atan2}(R_{21}, R_{11})$$

## How to Solve Inverse Kinematics (Step-by-Step)

**Given:** Desired end-effector pose $(p_x, p_y, p_z, roll, pitch, yaw)$

**Method: Damped Least Squares (DLS / Levenberg-Marquardt)**

1. **Construct target transform** $T_{target}$ from desired position and orientation (build rotation matrix $R_{target}$ from Euler angles)

2. **Initialize** joint vector $q^{(0)}$ with a seed (use current joint angles or zero)

3. **Iterate** until convergence (or max iterations):

   a. Compute current FK: $T_c = FK(q^{(k)})$, extract $p_c, R_c$

   b. Compute 6×1 error vector:
   $$\varepsilon = \begin{bmatrix} \Delta p \\ \Delta r \end{bmatrix} = \begin{bmatrix} p_{target} - p_c \\ \frac{1}{2}\begin{bmatrix}(R_c^T R_t)_{32}-(R_c^T R_t)_{23} \\ (R_c^T R_t)_{13}-(R_c^T R_t)_{31} \\ (R_c^T R_t)_{21}-(R_c^T R_t)_{12}\end{bmatrix} \end{bmatrix}$$

   c. Compute numerical 6×6 Jacobian by central differences ($\delta = 10^{-6}$ rad):
   $$J_{:,j} = \frac{FK(q + \delta e_j) - FK(q)}{\delta}$$

   d. DLS update:
   $$\Delta q = (J^T J + \lambda I)^{-1} J^T \varepsilon, \quad \lambda = 10^{-3}$$

   e. Clamp step: $\|\Delta q\|_\infty \leq 0.4$ rad

   f. Update: $q^{(k+1)} = q^{(k)} + \Delta q$

4. **Validate** using FK: compute $T_{FK}(q^*)$, check:
   - Position error: $\|p_{FK} - p_{target}\| < 10^{-4}$ m (0.1 mm)
   - Rotation error: $\|\Delta r\| < 10^{-3}$ rad (0.057°)
